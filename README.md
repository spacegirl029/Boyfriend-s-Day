# Build Your Dream Car 🏎️

A small pixel-art browser game made as a digital Boyfriend's Day gift.

## Run locally

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will give you a public URL for the game.

No server, build step, package manager, or API key is required.
